# 影片项目

每部影片都有独立文件夹，保存其剧本、研究笔记、分镜、提示词、镜头追踪和制作记录。

## 当前项目

| 影片 | 文件夹 | 状态 |
|---|---|---|
| The Look（那一眼） | [the-look](the-look/README.md) | 剧本 Draft 0.3 / 分镜 Draft 0.2 |

创建新影片时，使用简短、稳定的英文 slug 作为文件夹名称。影片专属决定应保存在各自文件夹中；只有经批准且计划跨影片复用的参考资料，才放入 `assets/`。

不同影片必须保持独立，不得未经明确创作决定就合并概念或转移故事元素。
