# Films

Each film has its own folder with its scripture research, script, storyboard, character and location references, prompts, shot tracking, and production notes.

## Current projects

| Film | Folder | Status |
|---|---|---|
| The Look (那一眼) | [the-look](the-look/README.md) | Development; screenplay draft 0.4 / storyboard draft 0.3 |
| The Sea of Tiberias (提比哩亚海边) | [sea-of-tiberias](sea-of-tiberias/README.md) | Development; screenplay and storyboard draft 0.1 |

Create a new folder using a short, stable English slug. Keep film-specific decisions inside that film's folder; move material to assets/ only when it is an approved shared reference. Separate film projects must not be blended without an explicit creative decision.

# 影片项目

每部影片都有独立文件夹，保存经文研究、剧本、分镜、人物与场景参考、提示词、镜头追踪和制作记录。

## 当前项目

| 影片 | 文件夹 | 状态 |
|---|---|---|
| The Look（那一眼） | [the-look](the-look/README.md) | 开发中；剧本 Draft 0.4 / 分镜 Draft 0.3 |
| The Sea of Tiberias（提比哩亚海边） | [sea-of-tiberias](sea-of-tiberias/README.md) | 开发中；剧本与分镜 Draft 0.1 |

创建新影片时，使用简短、稳定的英文 slug 作为文件夹名称。影片专属决定应保存在各自文件夹中；只有经批准且计划跨影片复用的参考资料，才放入 assets/。不同影片必须保持独立，不得未经明确创作决定就混合故事内容。
