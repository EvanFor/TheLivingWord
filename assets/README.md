# Shared Assets

This directory contains approved references intended for reuse across more than one film.

- `characters/`: reusable character identity and appearance references.
- `locations/`: reusable location designs and geography.

Keep film-specific variations inside the relevant film folder. Record a reference ID, version, description, and approval status for each asset. Large image and video binaries should follow the storage policy in [Versioning](../docs/versioning.md).
